Práctica final · HTML5

Construye una web con HTML

Trabajas para Caminando Senderos: observa la ruta y su página de consejos, y recréalas únicamente con HTML.

Objetivo de la actividad

Repasar los conocimientos básicos de HTML5: estructura del documento, etiquetas semánticas, encabezados, párrafos, listas, tablas, enlaces, imágenes, multimedia, accesibilidad y usabilidad.

Tu misión: crear la web de senderismo de dos páginas que se parezca al modelo en su contenido y estructura. No tienes que diseñarla ni copiar colores, márgenes o tipografías.

Qué tienes que hacer

  1. Abre el modelo. Se abrirá en otra pestaña. Explora las anclas de la ruta y entra en la página de consejos. Comprueba que puedes regresar a la ruta.
  2. Crea tu propia carpeta con dos documentos: index.html para la primera página y recursos.html para la segunda (consejos).
  3. Reproduce las dos páginas con HTML5. Mantén los contenidos, las anclas, las imágenes con sus fuentes, el vídeo, las listas, la tabla y la navegación de ida y vuelta entre las páginas. No utilices CSS, JavaScript ni atributos style.
  4. Añade las imágenes y el vídeo. Incluye las dos imágenes juntas, con sus atributos width y height, y el vídeo de YouTube mediante iframe.
  5. Pon un enlace para ver el tiempo
  6. Comprueba la estructura y la accesibilidad. Aplica como mínimo tres medidas de accesibilidad de las indicadas abajo. Incluye también un comentario HTML en tu código.
  7. Haz el test de repaso para comprobar tus conocimientos mediante 30 preguntas autocorregibles.

Accesibilidad: aplica al menos tres medidas

Elige un mínimo de tres de estas buenas prácticas. Todas se pueden implementar usando únicamente HTML, sin programar JavaScript:

  • Indicar el idioma de cada documento con <html lang="es">.
  • Añadir un texto alternativo adecuado con alt en cada imagen informativa.
  • Usar encabezados ordenados (h1, h2, h3…) sin saltos innecesarios.
  • Escribir enlaces descriptivos, evitando textos como «haz clic aquí».
  • Identificar los encabezados de la tabla con <th> y, cuando corresponda, scope; incluir <caption>.
  • Añadir un título descriptivo (title) al iframe del vídeo.

Importante: no se pide programar interacciones ni eventos de teclado. Los enlaces HTML nativos ya permiten navegar con el teclado sin JavaScript.

Qué debes entregar

Una carpeta comprimida en formato ZIP que contenga tus dos archivos HTML y los recursos locales que utilices. Ambos documentos deben enlazarse correctamente, y deben poder abrirse directamente en el navegador.

Antes de entregar, comprueba que has incluido encabezados, párrafos, listas, tabla con rowspan y colspan, dos imágenes con atribución visible, vídeo incrustado, etiquetas semánticas, un comentario HTML y tres medidas de accesibilidad como mínimo.
